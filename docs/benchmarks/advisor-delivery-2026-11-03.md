## Request contracts and invariants

Previously metrics reused the general pre-answer Executive JSON contract,
including a 1,200-character memo, user-facing additions and several directive
lists. Director similarly requested a broad memo and neutral control fields.
The prototype gives built-in external models compact views within their selected
AUTO mode. Manual ON/defaults and custom models retain their full API; OFF creates
no work. Ordinary pre-answer Executive advice stays full in both arms. Director
and metrics registry versions are `compact_delivery_v5`; enable/disable ownership
remains in TRN, with no new independent switch or classifier.

Director requests one memo of at most 240 characters, confidence and sparse
controls. Consultation force/skip/auto, both memory controls, temperature, answer
length and a clarification remain representable together. Metrics requests only
a 240-character monitoring memo and confidence, with no directives or mix-in.
It cannot steer an already returned answer or claim unobserved operations.
The full question remains available; existing 1,200-character signals JSON and
1,600-character context bounds stay. Metrics' answer/context snippets are partial,
so it must not certify omitted content or whole-answer correctness.

Each compact call caps output at **min(configured cap, 256 tokens)**, disables
continuations locally and requires a successful terminal completion plus strict,
typed, duplicate-free JSON. Wrapped/partial/extra/invalid output is unavailable
advice with empty controls, not a fast success. GPT completion caps also cover
hidden reasoning; the ceiling does not guarantee a usable response. No shared
client configuration is mutated. Effective contract/cap enter the model profile
before admission and actual start, preserving role/configuration isolation.

Native Director/metrics waits remain **1,600/2,500 ms**, capped by the real RPC
deadline. Executive overlap, cancellation ownership, cheap trivial-turn steering,
source/evidence/security rules and v4 recovery confirmation remain intact. There
is no new deterministic fallback disguised as external output. Compatibility
module defaults remain ON within requested modes; AUTO is not promoted by this study.
