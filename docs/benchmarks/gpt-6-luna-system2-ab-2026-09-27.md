## Reproduce

Set `OPENAI_API_KEY` in the environment, then run from the repository root:

```bash
LLM_PROVIDER=openai LLM_MODEL_ID=gpt-6-luna \
LLM_MAX_OUTPUT_TOKENS=2048 LLM_TIMEOUT=60 LLM_AUTO_CONTINUE=0 \
python3 sr-dual-brain-llm/scripts/benchmark_system2_ab.py \
  --modes off,on \
  --questions sr-dual-brain-llm/examples/system2_benchmark_questions_en.json \
  --critic-health-check on \
  --critic-health-attempts 2 \
  --critic-health-min-successes 2 \
  --critic-health-retries 0 \
  --critic-health-timeout 60 \
  --require-critic-health \
  --diagnostics unresolved \
  --output target/benchmarks/luna-ab-replay.json \
  --history ''
```
