# Advisor time-budget pilot — prospective protocol

Freeze and commit production code, runner and the complete three-case fixture
before provider calls. This is a controlled warm-history, frozen-draft mechanism
pilot, not a natural traffic-frequency, end-to-end savings or latency significance
study. Keep all prior TRN studies unchanged.

Use three new nontrivial questions: exactly three event-loop analogies, UDP loss
and detection in exactly two sentences, and exactly three HTTP payment retry
checks. Generate each natural primary draft once before processing. No authored
answer controls, memory records, persistence or retrieval-support intervention.
Explicit left lead, System2 auto/balanced, evaluative dial, Executive observe and
observer both are matched. Keep other nine modules AUTO in both profiles.

For each case, run exactly one real warmup turn from that frozen draft with the
three advisor gates manually ON. Snapshot the resulting Hypothalamus history for
each role/model: a usable completion or cancellation-censored lower bound, not
an assumed full completion time. Missing/failed observations remain unknown.
Do not replace or repeat an unfavorable warmup. The warmup answer is not scored.

Before each comparison cell, seed a fresh production session with the same
snapshot at age zero; ordinary 60-second expiry still applies during that turn.
This deliberate matched-history intervention isolates admission from learning
and arm order. It does not estimate how often the policy would inhibit in a
natural sequence of sessions. Run `untimed_advisors` (three advisors ON) versus
`timed_advisors` (three AUTO v2); ON reproduces the previous nontrivial-input
admission while keeping all other gate policies matched. Alternate arm order
across the fixed shuffled cases. No artificial outer deadline is injected:
Director/metrics use real local windows, Executive uses unknown-window fallback.

Compare every returned answer and the unchanged frozen draft using a blinded
`gpt-6-sol` judge, shuffled labels and the existing task/grounding/clarification
rubric. Require a literal nonempty answer quote for each pass/fail. Retain malformed
grades, unavailable cells, invalid/empty completions and provider fallbacks.
Never resample answers or tune thresholds on these cases. Report all planned,
available, graded and jointly graded cells and per-criterion paired regressions.

Production roles use `gpt-6-luna`, 2,048 tokens, 60-second provider timeout and no
continuations. Hard cap: **96 HTTP attempts** for the whole study. Count shared
draft generation, all warmups, both arms and judging, including cancelled work.
Stop new paid requests on transport/auth/quota errors. A returned invalid
completion allows only later unattempted cells, never a retry of that cell.
Persist partial paid work and retain failed generation as two unavailable arms.

Report reached/admitted gates plus per-role started/completed/timeout/cancelled/
usable-output counts. Structural usability is not answer correctness. Count
whole-turn post-draft HTTP attempts by role so replacement consultation cannot
masquerade as savings. Separate shared generation, warmup and judge overhead
from processing. Preserve unknown cancellation usage; never sum it as zero or
claim exact monetary savings. Wall-clock times are descriptive only.

Journal requests/responses without auth headers. Record the original warm-history
facts as replay inputs: instantaneous cached HTTP responses cannot reconstruct
observed live latency. Replay every generation/warmup/arm/judge request against
the frozen source and journal with zero live transport, seeding the original
facts in both comparison arms. Compare coverage, statuses, answers, gate decisions
and grades; ignore elapsed-time differences. Retain any timing-related mismatch
and do not enable fallback live calls. Raw artifacts stay in ignored
`samples/module-gating-advisor-budget-*/`; publish a safe aggregate projection.

No broad AUTO default promotion follows from three cases. Explain cold-start,
censoring, expiry and Executive overlap coverage limits alongside any gain.
