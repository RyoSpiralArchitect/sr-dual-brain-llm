## Trusted local controls and comparison

Compare `compact_remote` with `local_facts`, retaining one initially empty
production EngineSession per arm. Both use the confirmed-recovery ledger and all
twelve module modes in AUTO. Baseline bypasses only the new local planner;
treatment uses the production planner. Both keep compact remote Director/metrics
contracts where remote work is admitted. Manual ON/defaults, OFF, custom APIs,
Executive pre-answer advice and mandatory source/evidence/security rules retain
their authority. No classifier or separate deployment enable switch is added.

Local controls are sparse and have explicit `local_facts` provenance. They may
preserve consultation when normalized, capable, active System2 is explicitly ON,
or preserve an existing strong whole-long-term-memory restriction. They cannot
infer user intent from question length, memory absence, `remember=False`, or an
unsupported free-text classification. Mixed memory relay decisions are not a
blanket drop. Unknown length/temperature/clarification/memory needs stay neutral.
Memory steering is not deletion, persistence or proof of an external operation.

Only the registered Director AUTO policy may omit remote work for ready local
constraints. The local subset is applied before drafting; record both the actual
whole pre-draft stage duration and phase order, rather than timing construction
of a plan and then hiding an unconditional 1.6-second wait. Count actual routed
consultation and active System2 state. Never teach zero-duration local controls
to external latency history or call local advice an external completion. Native
Director/metrics waits remain 1,600/2,500 ms and real RPC caps remain 120 seconds.

## Structured assessment and independent calibration

Before the ten model turns, run the six independent paired calibration packets
in `examples/advice_assessment_calibration.json` through the same journal and
global budget. Their expected verdicts are fixed before calls and withheld from
the judge. Pairs cover positive unsupported assertions versus prohibitions or
negations, genuine uncertainty, requested-count drift, irrelevant context and
material omissions. Publish available checks, disagreements, uncertainty and
malformed packets. Calibration does not set runtime admission or adjust this
study after seeing outputs; preserve all planned cells even if calibration fails.

Grade all available final answers and primary drafts with the established task,
grounding and clarification rubric. Only explicitly requested obligations count.
Use shuffled labels, strict schema and literal quotes; unavailable answers and
malformed judgments do not become passes.

Capture external advice only before cancellation and local advice only from the
actual completed pre-draft application stage. Store `memo`, `control`,
`directives` (including `do_not_say`) and `mix_in` separately. Local trusted
constraints and reasons are input facts; remote input facts use the actual
1,200-character signals JSON/1,600-character context windows. Hide arm, source,
timing, confidence, profile and admission labels in judge packets; keep source
only for associating the resulting grades and exposure summaries.

Judge relevance, grounding, potential usefulness and critical coverage separately.
Every pass/fail identifies a canonical JSON-pointer field path and literal quote,
plus its interpretation as assertion/prohibition/control/uncertainty/other.
The validator retains the entire selected scalar field as private context, so
negation and qualifications are not lost to an isolated quotation. It does not
hard-code a passing verdict for prohibition fields: such a field can be irrelevant,
omit a necessary safeguard or contain a false embedded assertion. Unknowns may
remain uncertain. Original failures and complete context stay private, without
paid retries or silent rescoring.

Metrics is post-answer and cannot improve an answer already returned. Assess only
monitoring potential supported by the actual supplied snippet/report facts;
the complete final answer/reference cannot grant access to omitted content or
prove an unobserved operation. Local consultation preservation is a bounded
operational control, not a complete semantic answer. Model-based grades do not
establish causal downstream benefit or authoritative truth.

Report requested opportunities, starts, local/external exposures, missing output,
criterion pass/fail/uncertain counts, time/turns to usable controls and actual
pre-draft application/routing. Count probes, confirmation, induced ordinary work,
primary/support/repair and every timeout. Compare full turn cost without assigning
all independently sampled reply/history differences to the planner.

## Budget, replay and publication

Production uses `gpt-6-luna`; judges use `gpt-6-sol`. Base/final-judge output caps
are 2,048 tokens. Structured advice and calibration judges use 4,096 tokens per
packet; all have 60-second provider timeouts and no continuations. Compact remote
roles retain their 256-token or smaller configured cap. The hard **96-attempt
combined maximum** includes six calibration packets, ten complete model turns,
all support/consultation/repair/recovery/confirmation work, five final/draft judge
packets and up to five advice packets. No free warmup, resampling or paid replay.
Transport/auth/quota failure blocks new paid work. Unknown cancellation receipts
remain unknown; partial known tokens are not exact billed savings.

Replay starts with the six original calibration occurrences and consumes all
recorded HTTP requests, statuses and latency/recovery capabilities with zero new
transport. Require matching answers/drafts, canonical structured advice, both
grade sets, calibration verdicts, full gates, normalized resource operations,
source/pending counts, local-before-draft order and normalized routing facts.
Real elapsed time, timer stop reasons and asynchronous order are not reproduced;
never retrain latency from instant cached responses. Owned-task timeout and parent
cancellation are checked separately with real offline timers.

Raw artifacts stay in ignored `samples/module-gating-local-director-*/`.
Publish only safe aggregates/hashes, not prompts, advice fields, judge context,
quotes or credentials. A single correlated sequence cannot justify broad quality,
latency, cost or automatic-default claims. Retain omissions, calibration failures
and the existing remote feasibility limit rather than extending deadlines.
