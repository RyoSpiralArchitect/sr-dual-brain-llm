clean commit before any paid answer. This is a new study on post-#110 core code;
the #109 study and its amended selector/results remain immutable. No source,

## Fixed inputs and comparisons

Materialize twelve previously unexecuted tasks before calls. Main comparison uses
eight: Boolean entailment, SQL bag/NULL/window reasoning, async ownership/state,
and scoped evidence validity, each in two fixed stress tiers. Four other tasks,
one per domain at the higher tier, are reserved for a possible implementation
confirmation. No paid calibration, task selection, replacement or resampling.
Tiers are authored workloads, not a calibrated common monotonic scale.

Logic uses fresh satisfiable dense systems around the observed completion
boundary (8/12 variables). SQL uses 7/9 accounts with bag multiplicities, nullable
amounts, cutoff/tie/void interactions and reason-scoped exclusive ban intervals.
Events use 6/8 jobs with interleaved epochs, owner transfers, stale work and cancel/
finish races. Evidence queries revisit the same scopes/topics over multiple
times, including conflict, same-value multiple support, backdated validity,
derived/foreign supersession attempts and expired superseders with no revival.
Every input stays <=10,000 characters and has three complete explicit goals.
All conditions receive the same full task. Expected answers stay evaluator-only.

Main arms, using the original fixed six-permutation cyclic order (eight tasks is
near-balanced, not exactly balanced):

- `self_review`: the #109 four-call single-model initial/critique/revision/final
  audit comparator. Output caps 4096/2048/4096/2048. Its first generation is an
  auxiliary one-shot reference, not another paid arm.
- `dual_no_replan`: unchanged native RightBrainPolicy with left lead, manual
  System2 ON, goals AUTO, completion replanning OFF.
- `dual_replan`: identical native condition with completion replanning AUTO.

Native conditions use fresh sessions and matched case IDs/RNG/logical clocks.
Other balanced AUTO controls stay, Director/executive OFF. Current #110 critic
role/deadline behavior applies to both native arms; this does not isolate its
effect against historical versions. Each arm independently samples candidates.
Observe initial/final provenance without substituting drafts, critics or actions.
An OFF/AUTO difference is a system-configuration observation, not proof a
particular review caused it. Record actual planning exposure from private inputs
and bounded telemetry; reported goal coverage never means verified correctness.

ordinary continuation. Same per-trial all-provider output-ceiling allowance of

native review attempts, resolution provenance and known/unknown usage.

Primary observations: exact tasks, mean correct-item fraction, completion/schema/
workflow availability, paired higher/same/lower task deltas, per-domain/tier
